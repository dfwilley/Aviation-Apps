Checking the shared list…

The list is shared through the Aviation-Apps repository on GitHub, so a connected device sees the same list as every other one. Export still makes a backup file.

Connect this device

Any device can read the shared list. To save changes to it, this browser needs a GitHub access key (GitHub calls it a "fine-grained personal access token"). You do this once per device.

  1. Open GitHub's new access key page and sign in.
  2. Token name: N721NE To Do List. Expiration: pick the longest you're comfortable with.
  3. Repository access: choose Only select repositories, then pick Aviation-Apps.
  4. Permissions: under Repository permissions, set Contents to Read and write. Leave everything else alone.
  5. Press Generate token, copy the key (it starts with github_pat_) and paste it here.

The key is kept in this browser only. You can paste the same key on each device.
